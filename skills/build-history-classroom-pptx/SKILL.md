# 目标

依据任务目录中的 `资料摘要.md`、`教学设计.md`及教师确认的逐页蓝图，交付：

- `课堂课件.pptx`
- `教师备注.md`

除此之外不交付脚本、素材表、渲染图和检查报告。

# 启动条件

确认教学设计末尾已经包含逐页蓝图与素材选择。尚未确认时，只向教师确认一次；不得自行改变主线、环节、知识和关键材料。

学生可见的史实、引文、数据和学术判断必须来自资料摘要。缺少关键内容时返回上游，不由PPT阶段凭记忆补写。

# 视觉底线

- 画布固定为33.867 cm × 19.05 cm。
- 未明确指定时使用深色版本，主识别色为 `#1E869F`。
- 视觉来源依次为：教师本次指定模板、本地 `private-assets/templates/cloud-school-dark.pptx` 或浅色模板、文字规则后备方案。
- 真实模板只用于观察配色、标题、边界、留白和风格，再用原生对象重建；不得把模板整页截图作为背景。
- 标题使用微软雅黑加粗，正文使用黑体加粗，材料原文使用楷体，结论使用微软雅黑加粗，英文优先使用 Times New Roman。
- 正文不小于24 pt，通常使用28 pt以上；标题不小于28 pt，通常使用32 pt以上。
- 常规页面使用一致的顶栏和底栏，但底栏不显示“笔记”提示和任何页码。
- 每页在顶栏呈现L1环节标题，顶栏下方紧接L2知识点，再下方呈现L3材料或任务（如有），保证学生能够定位课堂进度。
- 结论条使用高饱和橙色背景，放大、居中，便于学生记录。
- 保持整套课件风格一致，同时根据材料研读、地图、比较、时间轴、关系图和总结等课堂需要改变内部构图，避免连续堆叠同款矩形。

# 课堂内容底线

- 主线只负责组织页面，基础知识、材料、问题、答案和学生笔记必须真实呈现。
- 每个主体环节都要完成“材料或知识支架—任务—思考—答案—阶段结论”，并推进下一问题。
- 允许部分页面内容较密；先保证一线教学需要，再处理版式，不为追求留白删掉知识。
- 媒体占位符可以保留，由教师交付后手动替换。占位符写清具体建议和观察任务，但不能成为整页唯一内容，也不能代替答案或结论。
- 文字史料、表格、时间轴和简单示意图可直接制作；未经教师确认的外部图片、地图、漫画和视频不自动搜索或插入。
- 同一任务的答案和结论优先在同一页动画揭示。表格待填内容保持真正空白，不用括号、问号和下划线占位，不另做内容重复的答案页。
- 图示只在关系明确时绘制，使用真实连接线表达方向和层级；无法确认历史关系时保留文字结构，不强行画图。
- 双版本课标原文与差异放在末尾隐藏附录，不打断课堂导入。
- 学生页面不得出现“AI生成”“教师备课页”“可隐藏”、制作提示、内部检查文字或空泛“谢谢”页。

# 技术路线

- 直接生成原生可编辑PPTX，不使用HTML转PPT、网页截图、PDF页面或整页图片冒充课件。
- 中间文件只放在任务目录的 `工作文件/` 中，固定使用 `draft.pptx`；不把过程文件散落到其他目录。
- 可直接执行现有脚本，不必读取脚本全文：
  - `scripts/Resolve-PrivateTemplate.ps1`：寻找本地私有模板；
  - `scripts/history_theme.mjs`：建立统一画布、配色和页面框架；
  - `scripts/Add-PowerPointAnimations.ps1`：写入原生动画；
  - `scripts/Test-PowerPointTextOverflow.ps1`：检查文字溢出和自动缩字。
- 原生动画无法可靠写入时停止并说明，不用复制页面伪装动画。

# 工作流

## 1. 读取模板与逐页蓝图

确定深色或浅色视觉来源，通读资料摘要和教学设计。按蓝图建立页面顺序，先检查每个环节是否具有足够知识、材料、任务、答案和结论。

## 2. 制作原生页面

先放置完整标题路径，再安排知识、材料和学生任务，最后安排动画答案与结论条。

根据课堂内容选择合适构图，不机械套模板示范页。互动表格、时间轴、关系图和占位符都保持原生可编辑。

## 3. 写入动画与备注

默认使用出现、淡入和擦除，以单击触发为主。问题和材料先出现，学生思考后再揭示答案、证据强调和结论。

教师备注逐页记录：

- 教学意图和建议用时；
- 预期回答、追问和纠偏；
- 动画单击顺序；
- 学生笔记；
- 媒体占位符的替换内容、比例、图注和核验要求。

## 4. 最终检查

只在最终文件上执行一次完整检查：

1. 逐页渲染，确认没有遮挡、异常换行和失衡空白；
2. 检查知识足以支持讲授和学生笔记，不存在空心占位页；
3. 检查每个主体环节的课堂链条和核心问题推进；
4. 检查完整标题层级、统一风格、字号和结论条；
5. 检查表格答案、图示关系和动画顺序；
6. 检查没有页码、“笔记”、制作提示、AI标记和重复答案页；
7. 运行文字溢出检查并修正全部问题；
8. 重新打开PPTX，确认可以正常保存、放映，备注与实际页数一致。

# 交付

将 `课堂课件.pptx` 和 `教师备注.md` 写入任务目录根部。交付说明只报告：

- 总页数与隐藏课标页数；
- 是否含教师后补媒体占位符；
- 动画、文字溢出和打开测试是否通过；
- 是否存在需要教师处理的明确事项。

不附带制作过程、矩阵、脚本、检查清单和内部统计。
