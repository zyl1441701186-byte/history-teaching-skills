# 目标

交付一套服务真实课堂的历史课件。教师可以在交付后手动替换媒体占位符，但课件本身必须同时承担问题推进、材料处理、知识落实、学生笔记和课堂检测，不能把知识、任务、答案或结论留给教师二次补写。

最终只交付：

- `课堂课件.pptx`
- `教师备注.md`

逐页蓝图、素材选择确认表、构建脚本、动画计划、渲染图和检查记录只保留在任务工作区。

- 底栏不得出现左下角“笔记”提示；任何页面不得显示右下角页码、当前页/总页数或其他页码变体；
- L1、L2必须为独立命名对象，L3存在时也必须独立；禁止用“环节·知识点”拼接文字冒充标题层级；
- 必须生成2025年与2020年课标原文对照页，默认置于末尾并设置为隐藏附录；不得在学生可见页面写“教师备课页”“可隐藏”；
- 教学必要时允许高密度页；
- 结论条使用高饱和橙色，放大居中；
- 不自动搜索或插入未经教师确认的外部图片、地图、漫画和视频；
- 不采用商务卡片墙、仪表盘和HTML转PPT；
- 禁止用括号、问号、下划线模拟待填答案；答案必须作为独立文本框在同一页动画出现；
- 禁止把“AI生成”、制作提示、任何页码、空方框和内部检查文字留在学生视图；
- L1必须包含环节序号和有意义的环节名称，不得只写“环节1”“环节二”；
- 除用户明确要求外，禁止用“谢谢”或“THANKS”作为结束页；
- 允许课堂成品保留教师确认的媒体占位符；占位符不能代替知识、材料文字、任务、答案或结论，也不能成为整页唯一内容；
- 不交付源码、素材表和检查文件。

# 启动条件和优先级

必须有已经确认的：

1. `教学设计.md`
2. `课件制作清单.md`
3. `课件素材建议表.md`

还应读取 `资料核心摘要.md` 以约束史实、引文、概念和来源。

以上四个输入必须位于同一个Trae任务目录，同目录必须存在 `工作区信息.md`。最终交付和所有制作中间文件只能写入该任务目录。

四个输入必须同时包含：双版本课标完整原文与页码、独立L1/L2/L3页面接口、主线贯穿度矩阵、视觉证据覆盖矩阵、互动表格动画计划、图示结构说明和学生视图材料核验状态。缺少时停止并返回上游补齐。

凡拟进入学生视图的材料标记为 `待核原文`、`待核原书`、`待确认`、`关键缺口` 或 `仅作线索`，必须返回上游或由教师核验后再继续。不得一边在来源清单标记待核，一边把引文或结论写入PPT。

优先级：教学设计决定目标、主线、环节和知识；课件制作清单决定课堂动作和揭示顺序；素材建议表决定需要教师确认的外部视觉意图；资料摘要决定证据边界；用户明确指定的模板或主题决定视觉语言。未指定时依次尝试私有深色模板和文字规范深色版。

冲突影响史实、知识或教学逻辑时停止，不得自行裁决。

# 强制技术路线

- 直接生成原生 `.pptx`，优先使用PptxGenJS或等效PowerPoint自动化，以原生形状、文本、表格、线条和图片对象手工搭建页面。
- 禁止HTML、网页截图、PDF或整页图片作为版式中间产物。
- 学生可见文字、标题、结论、表格、时间轴和示意图保持原生可编辑。
- 使用 [scripts/Resolve-PrivateTemplate.ps1](scripts/Resolve-PrivateTemplate.ps1) 检测本地私有模板；从最终选中的真实模板或文字规范中整理颜色、构图、层级、边界与强调方式，建立 `visual-language-spec.md` 与 `layout-system.json`。
- 使用 [scripts/history_theme.mjs](scripts/history_theme.mjs) 或等效主题模块统一生成页框、标题层级、面板、结论条、占位符和底栏；默认主题为 `dark`。
- 允许根据课堂容量重新组织既定设计语言，但不得退化为商务汇报、卡片墙或无辨识度的通用主题。
- 需要动画的对象设置稳定对象名。
- 先运行 [scripts/Test-PowerPointAnimation.ps1](scripts/Test-PowerPointAnimation.ps1)；失败时停止。
- 动画后运行 [scripts/Inspect-PptxTiming.ps1](scripts/Inspect-PptxTiming.ps1)。
- 每次生成后运行 [scripts/Test-PowerPointTextOverflow.ps1](scripts/Test-PowerPointTextOverflow.ps1)，任何溢出或自动缩字都必须修正。
- 每次生成后运行 [scripts/Test-HistoryClassroomStructure.ps1](scripts/Test-HistoryClassroomStructure.ps1)，拦截缺失标题层级、制作残留、括号占位、页码对象和“笔记”提示。
- 每次生成后运行 [scripts/Test-HistoryClassroomReadiness.ps1](scripts/Test-HistoryClassroomReadiness.ps1)，拦截可见课标附录、空心页面、低信息密度、课堂链角色不足、无语义L1、空结束页和教师备注页数不一致；媒体占位符本身不构成失败。

# 工作流

## 1. 建立任务工作区

读取 `工作区信息.md` 确定任务根目录。以下制作目录必须建立在该任务目录的 `工作文件/课件制作/` 下，不得建立在Skill目录、桌面或当前进程目录。

```text
工作文件/课件制作/
├── source/
├── build/
├── rendered/
├── qa/
├── style-audit.txt
├── visual-language-spec.md
├── layout-system.json
├── deviation-log.txt
├── title-path-manifest.json
├── layout-coverage.json
├── interaction-manifest.json
├── 素材选择确认表.md
└── animation-plan.json
```

中间PPTX固定命名为 `build/draft.pptx`，不得在 `build/` 中生成与最终交付同名的 `课堂课件.pptx`。不修改用户原文件。

## 2. 选择并审计云校视觉来源

按以下顺序选择且只选择一个视觉来源：

1. 用户在当前任务中明确提供并指定的模板；
2. 本Skill安装目录 `private-assets/templates/` 中与所选主题对应的私有模板；
3. 本Skill文字规范中与所选主题对应的版本。

用户未在当前任务指定模板时，先运行私有模板探测器。返回 `private-template` 时，完整渲染并审阅该模板全部页面，记录背景与面板配色、青色和金色强调、标题层级、品牌元素、内容区比例、留白和视觉节奏；返回 `written-fallback` 时，将 [云校视觉语言文字规范](references/cloud-school-template.md) 转写为 `visual-language-spec.md` 与 `layout-system.json`。不得把深浅两套视觉体系混用。

真实模板和文字规范都只提供设计思路，不提供本课内容，也不限定课堂版式数量。不得把模板中的示范文字、版式用途说明和其他非本课内容带入成品。私有模板可复制到任务临时目录进行渲染，但不得进入最终交付、公开仓库、安装日志或共享压缩包。

## 3. 执行知识覆盖审计

从教学设计的知识覆盖矩阵提取全部必备知识，建立内部映射：

```text
知识ID → 教学环节 → 课堂动作 → 学生可见页面 → 笔记落点
```

以下内容只出现在教师备注中不算覆盖：基础史实、关键概念、制度内容、主要过程、因果关系、历史影响和要求学生记录的结论。

教学主线只作为组织线索，不得占用页面主体却挤掉知识内容。发现课件清单漏项时停止并回到教学设计修正，不得由PPT Skill擅自补写史实。

从 `CURR-2025`、`CURR-2020` 和 `CURR-DIFF` 建立课标页。完整原文无法在一页以24 pt以上呈现时拆为续页；不得改写、截去差异关键句或只保留AI概括。

区分导入锚点、教学主线和核心问题。逐环节填写“子问题—证据—阶段判断—对核心问题新增内容”。只在开头和结尾出现的文物不得充当整课主线；贯穿度不足时返回教学设计修正。

## 4. 建立逐页蓝图与版式映射

每页登记：

- 页面序号（只用于制作蓝图，不得上屏）和完整标题路径；
- 分离的L1、L2、L3与当前任务对象名；
- 材料/证据、任务、答案和结论的课堂角色对象名；
- 所选风格版本和版式类型；
- 使用的统一页框、标题区、内容区、媒体区、结论区和品牌元素；
- 所属教学环节和知识ID；
- 唯一主要课堂任务；
- 学生初始可见内容；
- 文字、数据和原生图形；
- 外部视觉素材意图；
- 学生任务和预期产出；
- 笔记落点与结论条；
- 动画对象、顺序和揭示内容；
- 互动表格的空单元格、答案对象和同页动画；
- 图示节点、关系、方向、层级和连接线标签；
- 与前后页关系；
- 建议用时及必讲、可压缩、可跳过标记。

按学生认知和页面容量拆页，不按教案章节机械转换。

除封面、隐藏课标附录和少量转折页外，每个常规教学页至少承担材料/知识支架、学生任务、处理、答案、结论中的三项；连续两页必须合计完成完整认知链。只有标题、主线口号、巨大空框或结论条的页面不得进入蓝图。

常规新授课的学生可见教学页通常控制在14至22页，常规教学页有效中文字符建议为140至320，整套中位数不得低于150。占位符说明、页眉页脚、重复标题和制作提示不计入有效知识字符。数字只用于筛查异常，最终仍须逐页判断知识点、课堂动作和笔记落点是否真实存在。

每个输出页必须映射到一类已登记的课堂版式，如单材料研读、图文任务、比较归纳、时间轴、因果关系或知识总结。允许根据教学需要手工设计新课堂版式，但必须继续使用同一套顶栏、底栏、配色、字体、边界和品牌语言。

整套课件至少使用4种构图家族，不得连续3页使用完全相同的内部构图。除真实表格、时间轴或流程节点外，一页不得用5个以上同款矩形分别包装普通句子。

## 5. 执行教师素材确认关口

根据逐页蓝图生成临时 `素材选择确认表.md`，列出每一页的外部图片、地图、漫画和视频建议。

40至45分钟课时默认应有8至12项A/B级视觉意图，至少覆盖3种媒介，每个主体教学环节至少1项候选。少于6项时暂停并要求教师确认“视觉证据覆盖不足”；不得直接按纯文字方案继续。

每页必须由教师选择：

- 不使用素材；
- 保留占位符；
- 已有指定素材但仍保留占位符；
- 暂不确定，保留可删除占位符。

必须暂停并等待教师确认。用户已提供完整确认表时可以直接读取。未确认不得制作整套PPT。

确认“不使用素材”的页面重新设计为纯文字、表格、时间轴或原生关系图，不得留下空洞区域。其他选择只生成占位符，不插入实际外部文件。

确认结果可以包含“保留占位符”“已有指定素材但仍保留占位符”或“暂不确定”。这些状态不改变交付文件名；但每个占位页必须同时具备完整的已核验知识内容、可执行任务、动画答案和笔记结论，不得等教师补图时再补课堂逻辑。

## 6. 执行动画能力预检

运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/Test-PowerPointAnimation.ps1 -WorkDir <任务工作区>
```

只有真实创建、保存、重开并读回动画序列后才能继续。

## 7. 手工重建并原生制作PPTX

- 依据 `visual-language-spec.md` 和 `layout-system.json` 从空白演示文稿手工重建，不直接复制示范页；
- 以所选真实模板或文字规范的画布、背景、面板、边缘品牌区、青色与金色强调及版式节奏为风格基准；私有模板中的校徽或云校标识只在授权的个人课件中使用，不得导出为公共资产；
- 所有常规内容页使用相同顶栏和底栏；一级、二级、三级标题依次紧接，保证学生随时定位课堂进度；
- L1对象命名为 `S##_L1Title`，L2为 `S##_L2Title`，L3为 `S##_L3Title`；常规内容页的L1、L2不得为空；
- L1写成“环节序号＋语义名称”，不得使用只有编号的环节名；
- 课堂链对象分别使用 `S##_Material_01` 或 `S##_Evidence_01`、`S##_Task`、`S##_Process_01`、`S##_Answer_01`、`S##_Conclusion`；常规教学页至少存在三类角色；
- 先安排知识、材料和学生任务，再安排答案和结论；
- 外部视觉素材统一使用 `MEDIA-PXX-XX` 占位符；
- 表格、时间轴、制度图、因果图和简单统计图可以原生生成，但只能使用已核验知识或数据；
- 互动表格保留真正空白单元格，答案使用无填充、无线条的独立文本框覆盖对应单元格，并按教学顺序在同一页出现；
- 简单图示使用原生形状和真实连接线，先画连接线再画节点；复杂关系优先使用Graphviz或等效工具生成SVG，不得用成排同款矩形代替结构设计；
- 对全部文字显式设置字体、字号、边距和行距；
- 禁止自动缩小文字和整页扁平化。

课堂主序列从导入开始推进。双版本课标页完成后移动到末尾，使用PowerPoint隐藏幻灯片属性从放映中跳过。结尾完成核心问题回答、检测、迁移或作业，不增加空泛致谢页。

所有学生可见内容必须是新建的原生可编辑对象。不得把模板页截图、整页图片或模板示例文字当作背景，也不得用截图模拟可编辑版式。

## 8. 执行容量与溢出检查

先做版式容量检查，再运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/Test-PowerPointTextOverflow.ps1 -PptxPath <课堂课件.pptx> -OutputJson <qa/text-overflow.json>
```

发现溢出时按顺序处理：删除重复修饰、改成结构化表达、拆为同层级续页、将教师背景说明移入备注。不得删除必备知识，不得突破字号下限，不得启用自动缩字。

## 9. 写入并验证原生动画

默认只使用出现、淡入和擦除，以单击触发为主。问题先出现，学生处理后再显示证据强调、答案和结论条。

同一材料上形成的答案、同一表格的填写结果、同一图示的推演过程必须优先在同页揭示。禁止默认复制成“空白页＋答案页”；只有认知任务改变或最终展开状态无法容纳时才允许另起页，并记录理由。

动画写入后重新打开并检查时间轴、对象顺序、文件修复提示和备注一致性。再次运行文字溢出检查，防止动画保存过程改变版式。

## 10. 生成教师备注

逐页记录：完整预期回答、追问、纠偏、过渡、时间、动画单击、学生笔记和外部素材手动插入说明。

每个占位符必须在备注中说明：建议内容、教学作用、比例、裁切、图注、来源核验、动画时机以及不插入时的替代方案。

## 11. 逐页验收

必须完成：

1. 渲染全部页面为PNG；
2. 逐页全尺寸检查；
3. 运行文字溢出与自动缩字检查；
4. 检查知识覆盖矩阵全部落到学生可见页面或笔记结论；
5. 检查完整标题路径与统一标题系统一致；
6. 检查正文、材料、表格、人工标注均不低于24 pt；
7. 检查标题不低于28 pt，结论不低于32 pt；
8. 检查问题先于答案、结论最后出现；
9. 检查占位符ID、比例和教师备注一致；
10. 检查PowerPoint可正常打开、保存和放映；
11. 检查所有计划动画均为原生时间轴；
12. 检查每页都有版式映射，统一顶栏、底栏、边缘品牌区和水印结构无意外丢失，且底栏没有“笔记”提示或页码；
13. 检查不存在示范文字、模板页截图或不可编辑的整页背景；
14. 对照所选真实模板或文字化视觉规范执行风格一致性检查，而非像素级复刻检查；
15. 检查所有常规内容页都有独立L1、L2对象，L3按清单完整存在；
16. 检查课标原文、版本差异和页码完整进入课标依据页；
17. 检查互动表格没有括号占位、重复答案页，答案对象与动画数量一致；
18. 检查至少4类构图家族、无连续3页同构图、无矩形卡片墙；
19. 检查图示使用正确关系、方向和连接线，线条不穿过节点或标签；
20. 检查视觉证据覆盖矩阵、媒介类型和教师确认状态；
21. 检查不存在“AI生成”、内部提示、空方框、“笔记”提示、任何页码和其他制作残留；
22. 检查内容近似页面，删除可以同页动画完成的题目页/答案页重复。
23. 检查每个主体环节完成材料—任务—处理—答案—结论链条，并产生一项对核心问题的新回答；
24. 检查课标页全部位于末尾连续隐藏附录，导入前没有课标说明页；
25. 检查占位符没有成为整页唯一教学内容，没有替代知识、任务、答案或结论；
26. 检查学生视图使用的材料全部为已核验或可直接使用状态；
27. 检查备注总页数、逐页标题、动画页数和占位符数量与实际PPTX一致；
28. 检查中间文件与最终文件不同名，所有QA针对根目录实际交付文件重跑；
29. 检查结尾不是“谢谢”页，而是核心问题回答、迁移、检测或作业。

任何一项未通过都必须修改并重新检查。

# 失败与降级

- 缺少已确认教学设计、课件清单或素材建议表：停止。
- 教师尚未完成逐页素材选择：暂停，不得生成整套课件。
- 教师选择保留占位符：照常生成课堂课件，但必须记录逐项替换说明，并保证不补图也能看出完整课堂逻辑。
- 知识覆盖矩阵与课件清单冲突：返回教学设计修正。
- 导入锚点无法贯穿各主体环节：将其降级为导入素材并返回教学设计重建主线。
- 学生视图材料仍含待核状态：停止，不得把核验责任转移到备注后继续制作。
- 双版本课标原文、标题路径、视觉证据覆盖、互动表格计划或图示结构缺失：返回教学设计修正。
- 用户指定或私有模板缺失、损坏或无法渲染：使用对应主题的文字规范继续手工重建，在偏差日志和教师备注中明确标记 `written-fallback`，不得假称已参考真实模板。
- 既有版式无法承载某页内容：在统一视觉系统内设计新的课堂版式或拆页，不得缩小字号、挤压知识或改成商务版式。
- 无法生成原生PPTX、原生动画、逐页渲染或文字溢出检查：停止。
- 不得静默改为HTML、静态PPT、图片化页面或复制页伪动画。

只有用户明确同意后才可采用复制页模拟动画，并在备注中标明。
