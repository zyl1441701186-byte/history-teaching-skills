# 课堂构图与图示语法

## 构图原则

统一顶栏、底栏、配色、字体和品牌结构；变化发生在内容区。每页只能有一个主要视觉中心和一个主要课堂任务。

至少使用4种构图家族，不得连续3页同构图：

| 构图家族 | 适用任务 | 视觉中心 |
|---|---|---|
| 文物沉浸式导入 | 观察细节、生成问题 | 大幅文物或局部特写 |
| 地图＋标注 | 时空定位、分布和变化 | 地图及标注层 |
| 多图证据比较 | 生产、文化、制度比较 | 2至6项证据图像 |
| 史料对读 | 互证、冲突、立场分析 | 两组短材料与证据标记 |
| 时间轴与阶段 | 过程和分期 | 单一时间尺度 |
| 因果推演 | 原因、机制、结果 | 有方向的因果关系 |
| 制度关系图 | 层级、互动和运行 | 关系网络或层级树 |
| 表格填写 | 比较、整理和检测 | 原生表格与逐项答案 |
| 知识讲授 | 必备知识和笔记 | 一组结构化知识，不是卡片墙 |
| 综合收束 | 回答核心问题 | 已使用证据的重新组织 |

## 矩形限制

- 不为每句话单独加矩形；
- 除真实表格、时间轴或图示节点外，一页不超过5个同款矩形；
- 材料可通过留白、字体、引文线和底色分区，不默认放进圆角卡片；
- 禁止卡片网格、仪表盘、按钮、标签云和商务流程图；
- 结论条保留，但不得成为每页唯一变化。

## 图示设计顺序

1. 读取上游图示ID及结构说明；
2. 判断时间、因果、层级、互动、循环或比较；
3. 先创建连接线，再创建节点；
4. 用位置、形状、颜色或大小编码角色差异；
5. 标注必要的关系词；
6. 按课堂推理顺序设置动画；
7. 检查最终展开状态。

简单图示使用PowerPoint原生形状和真正的连接线。复杂网络、谱系或多层拓扑优先使用Graphviz输出SVG；SVG可以作为图形对象插入，但文字结论仍须原生可编辑。

## 禁止

- 把关键词逐个塞进等大圆角矩形；
- 用Unicode箭头代替需要吸附节点的连接线；
- 连接线穿过节点、文字或其他关系；
- 节点和连接线没有语义差别；
- 从散文段落自行发明因果关系；
- 为美观省略条件、限定语或关键知识。

## 图示验收

- 图示与上游节点、关系、方向、层级一致；
- 阅读方向明确；
- 同级节点视觉一致，不同角色可区分；
- 连接线位于节点后方，箭头端清晰；
- 标签不压线、不越界；
- 动画顺序复现课堂推理，而不是随机逐个出现。
