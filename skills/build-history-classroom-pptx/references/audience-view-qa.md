# 学生视图与成品残留检查

## 禁止出现在学生视图

- `AI生成`、`AI Generated`；
- 制作提示、版式用途、内部检查、建议用时和必讲标记；
- `□`、括号、问号、横线等伪空格；
- 模板示例文字；
- 错误总页码；
- 调试ID和对象名；
- 完整网址、版权核验提示和教师操作说明；
- 空文本框、默认提示语和不可见残留对象。

`MEDIA-P##-##` 是教师手动替换前唯一允许显示的制作ID；其余内部信息进入备注。

## 页码

页码分母必须读取最终PPTX实际页数，不得使用蓝图预计页数。课标页、隐藏页或教师备课页如保留在文件中，也计入总页数；如不希望显示连续页码，使用单独的备课页标识，不伪造分母。

## 重复页面

对相邻页面提取标准化文本，检查：

- 空表页与答案表页；
- 空流程图与完整流程图；
- 两张内容近似的知识结构总结；
- 仅增加答案而其他内容不变的页面。

可以同页动画完成时必须合并。真正的新认知任务可以保留，并在逐页蓝图说明差异。

## 标题路径

常规内容页必须存在：

- `S##_L1Title`：非空；
- `S##_L2Title`：非空；
- `S##_L3Title`：上游提供L3时非空；
- 当前任务：位于标题区下方或内容区首行。

封面、候场、目录和结束页在 `title-path-manifest.json` 中登记例外。课标、练习、总结和素材占位页不是例外。

## 视觉审阅

自动检查通过后仍须逐页全尺寸查看。程序无溢出不代表具备设计感；必须同时检查视觉中心、构图变化、证据可见性、阅读顺序和后排辨识度。
