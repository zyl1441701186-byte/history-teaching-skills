# 互动表格与答案揭示

## 默认行为

课堂填写、比较和归纳表格必须在同一页完成“任务—思考—答案—结论”。不得默认复制题目页和答案页。

## 制作方法

1. 使用原生PowerPoint表格创建表头、行列标题和固定内容。
2. 待填单元格保持真正空白，不放括号、问号、横线、空方框或空格字符。
3. 每项答案创建独立透明文本框，精确覆盖对应单元格内容区。
4. 答案对象命名为 `S##_Table_<表格ID>_Answer_<行>_<列>`。
5. 答案对象使用无填充、无线条、与表格一致的字体和对齐。
6. 按教学设计指定的行、列或讨论顺序设置“出现”或“淡入”。
7. 最后一项答案后再显示表格结论或学生笔记条。

## 验收

- 空白状态没有任何占位符号；
- 答案对象数量等于待填单元格数量；
- 每个答案对象都在原生动画时间轴中；
- 文本框不越过单元格边界；
- 最终展开状态可读且不溢出；
- 教师备注写明每次单击出现的答案；
- 不存在内容高度相似的独立答案页。

只有以下情况允许另起页：

- 答案出现后进入新的比较、解释或迁移任务；
- 同页最终状态无法在字号下限以上容纳；
- 教师明确要求保留独立答案页。

必须在偏差日志写明理由。
