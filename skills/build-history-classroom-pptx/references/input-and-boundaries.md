# 输入、边界与优先级

## 必需输入

- 已确认的 `教学设计.md`
- `课件制作清单.md`
- `课件素材建议表.md`
- `资料核心摘要.md`

用户模板或参考课件只作为品牌、页框、空间组织和动画习惯参考，不提供本课事实和答案。

## 输入职责

- 教学设计：控制主线、目标、环节、问题、知识、结论和时间。
- 课件制作清单：控制课堂动作、学生可见内容和揭示顺序。
- 素材建议表：控制需要教师确认的视觉和音视频意图。
- 资料摘要：控制史实、课标、引文、观点、数据和材料边界。
- 模板：控制可借鉴的视觉系统，不改变教学逻辑。

## 外部媒体边界

本 Skill 不联网搜索、不下载、不筛选、不识别、不插入外部图片、历史地图、漫画和视频。

教师即使指定了文件，也只在确认表和备注中记录文件名，并在PPT中保留相应占位符，等待教师交付后手动替换。

允许原生生成基于已核验内容的表格、时间轴、关系图、制度示意图和简单统计图。禁止用图形伪造文物、档案、历史地图或原始图像。

## 冲突

- 教学设计与资料摘要冲突：停止。
- 课件清单遗漏知识覆盖矩阵：返回教学设计修正。
- 素材建议与教学设计冲突：以教学设计为准并要求教师确认。
- 参考课件冲突：只保留视觉参考。

不得编造学校、班级、教师、课时、教材版本、学生回答、引文、数据或媒体来源。
