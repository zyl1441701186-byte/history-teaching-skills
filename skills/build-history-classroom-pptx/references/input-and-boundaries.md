# 输入、边界与优先级

## 必需输入

所有必需输入和 `工作区信息.md` 必须位于同一个Trae任务目录。不得从不同课题、不同日期的工作区拼接输入。

- 已确认的 `教学设计.md`
- `课件制作清单.md`
- `课件素材建议表.md`
- `资料核心摘要.md`

输入还必须包含：`CURR-2025`、`CURR-2020`、`CURR-DIFF`、逐页L1/L2/L3、主线贯穿度矩阵、视觉证据覆盖矩阵、互动表格答案计划、图示结构说明和学生视图材料核验状态。缺失时返回上游，不得由PPT阶段猜测。

学生视图使用清单中出现 `待核`、`待确认`、`关键缺口` 或 `仅作线索` 时停止。教师背景区可以保留缺口，但不得把同一材料安排进学生页面。

公开Skill以文字化规则固化云校视觉语言，不附带学校模板文件；个人安装可以通过 `private-assets/templates/` 提供私有深浅模板。用户在当前任务中明确指定其他正式模板时，当前用户模板优先。模板只控制视觉语言和空间倾向，不提供本课事实和答案。

## 输入职责

- 教学设计：控制主线、目标、环节、问题、知识、结论和时间。
- 课件制作清单：控制课堂动作、学生可见内容和揭示顺序。
- 素材建议表：控制需要教师确认的视觉和音视频意图。
- 资料摘要：控制史实、课标、引文、观点、数据和材料边界。
- 视觉规范或用户模板：提供配色、品牌气质、构图、层级和视觉节奏，制作工具据此手工重建，不改变教学逻辑。

## 视觉语言默认值

- 用户没有明确要求：优先使用私有深色模板，缺失时使用文字规范深色版。
- 用户明确要求浅色：优先使用私有浅色模板，缺失时使用文字规范浅色版。
- 用户明确要求深色：优先使用私有深色模板，缺失时使用文字规范深色版。
- 用户明确提供其他模板：使用用户当前指定的模板，不混入另一套视觉语言。

## 外部媒体边界

本 Skill 不联网搜索、不下载、不筛选、不识别，也不插入未经教师确认的外部图片、历史地图、漫画和视频。

教师指定文件但仍选择手动替换时，可以在 `课堂课件.pptx` 中保留结构化占位符；占位符不得替代任何知识内容、任务、答案或结论。

允许原生生成基于已核验内容的表格、时间轴、关系图、制度示意图和简单统计图。禁止用图形伪造文物、档案、历史地图或原始图像。

## 冲突

- 教学设计与资料摘要冲突：停止。
- 课件清单遗漏知识覆盖矩阵：返回教学设计修正。
- 素材建议与教学设计冲突：以教学设计为准并要求教师确认。
- 既有版式与内容冲突：在同一视觉系统中换用课堂版式或拆页，不得覆盖品牌对象、缩小字号或切换到商务版式。
- 普通参考课件与云校风格参考冲突：视觉风格以已选文字规范或用户指定模板为准，教学组织以教学设计和课件清单为准。

不得编造学校、班级、教师、课时、教材版本、学生回答、引文、数据或媒体来源。
