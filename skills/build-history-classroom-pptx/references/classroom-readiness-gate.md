# 课堂可用性闸门

## 核心判断

格式合格、标题完整、没有溢出，不等于可以上课。最终课件必须先通过课堂可用性，再通过视觉和技术检查。

课堂可用性的最低单位不是“页面”，而是完整的认知链：

```text
材料或知识支架 → 学生任务 → 处理过程 → 答案或判断 → 可记录结论 → 下一问题
```

每个主体环节至少完成一条认知链。真实文物、地图、表格、文字史料和示意图必须承担证据功能；等待教师补入的占位符必须写清未来材料的证据任务，不能只是装饰或空框。

## 交付状态

### 课堂成品

文件名为 `课堂课件.pptx`。必须满足：

- 允许保留教师已经确认、准备课后手动替换的图片、地图、漫画或视频占位符；
- 占位符只代表“媒体文件待替换”，不得代表“知识内容、史实、题目、答案或结论待补写”；
- 每个占位页即使暂不插入真实媒体，仍有足够的已核验文字证据、知识支架、问题、答案和笔记结论维持课堂链条；
- 占位符写清具体素材、观察任务、替换尺寸和唯一ID，不写“待定图片”“这里放图”等无效提示；
- 没有只能依赖教师临场口述或板书才能成立的空页；
- 课标原文页位于末尾隐藏附录，不打断学生放映顺序；
- 教师备注页数、标题和动画与该文件完全一致。

### 内容施工稿

只有当知识、史实、问题、答案、结论、材料身份或史料原文仍未核验时，才使用 `课堂课件-内容施工稿.pptx`。此状态不得宣称“课堂可直接使用”，也不得与媒体占位符混为一谈。

用户已经确认“由教师手动补入图片和视频”时，媒体占位符不是降级原因，仍交付 `课堂课件.pptx`。

## 课堂顺序

学生可见放映顺序默认采用：

```text
封面 → 情境导入 → 核心问题 → 主体环节 → 回答核心问题 → 检测或迁移
```

双版本课标原文与差异必须保留，但默认移动到课件末尾并设为隐藏附录。不得把三至四页课标说明放在导入之前。幻灯片上不得显示“教师备课页”“可隐藏”等操作提示。

结尾必须完成核心问题的回答、迁移或任务布置。除用户明确要求外，不增加“谢谢”“THANKS”等空结束页。

## 主线与导入锚点

区分：

- `导入锚点`：负责吸引注意和生成问题，如一件文物；
- `教学主线`：负责组织全部主体知识和问题推进；
- `核心问题`：学生在结尾能够用本课证据回答的问题。

导入文物只有在每个主体环节都能产生必要的部分答案时，才可以兼任教学主线。只在开头和结尾出现的文物必须标为导入锚点，不得用它包装整课主线。

每个主体环节设置一个主线检查点：

| 环节 | 本环节子问题 | 使用证据 | 阶段判断 | 对核心问题新增了什么 |
|---|---|---|---|---|

若某一主体环节不能填写最后一列，说明主线没有真正贯穿。

## 页面课堂链

常规教学页至少承担以下三项，连续两页必须合计完成全部五项：

1. 可处理的材料或明确知识支架；
2. 学生可见任务或问题；
3. 学生需要进行的观察、比较、提取、解释或判断；
4. 动画揭示的答案、证据标记或教师归纳；
5. 可记录的阶段结论。

只显示主线口号、巨大空框、单张未插入图片说明、泛化流程图或教师讲稿提示的页面不合格。占位符不计作知识支架；占位符旁已经呈现的史实、史料摘录、观察任务和结论才计入课堂链。

## 内容密度

允许并鼓励高密度课堂页，也允许少量低密度转折页。低密度页必须承担导入、转折、核心提问或关键结论之一。

对40至45分钟常规新授课，建议把学生可见教学页控制在14至22页；常规教学页的有效中文字符通常为140至320，整套常规教学页中位数不得低于150。数字只是异常筛查线，不替代逐页教学判断：

- 少于90个有效字符且没有真实表格、关系图或足量史料的页面，默认判为内容空心；
- 连续两张少于120个有效字符的常规教学页，必须合并或说明其必要的课堂动作；
- 超过320个有效字符时优先拆为同一标题路径的连续页，不得缩小字号；
- 素材占位符文字、页眉页脚、重复标题、制作说明不计入有效知识字符。

不得用“一个知识ID已经出现”代替知识落实。知识覆盖检查同时核对：

- 学生看到了什么具体史实、概念、制度或关系；
- 学生用什么材料处理它；
- 学生最后记录什么；
- 该结论如何进入下一问题。

连续出现大面积空白、只有占位框或只有标题与结论条时，判定为内容空心化。

每个主体环节至少包含：

- 1页具体知识建构：呈现本环节必须讲清的史实、概念、制度内容、过程或关系；
- 1次材料处理：真实材料或明确的媒体占位意图与可执行观察任务；
- 1项学生可记录的阶段结论；
- 1个把阶段结论推进到下一子问题的过渡。

## 材料核验

进入学生视图的史料、数据、署名观点、文物身份、地图信息和课标表述必须标记为 `可直接使用` 或 `已核验`。素材占位符可以描述建议搜索对象，但不能把未经核验的具体史实、图注或引文当成既定内容。

`待核原文`、`待核原书`、`待确认`、`关键缺口` 和 `仅作线索` 不得进入课堂成品。无法在制作前解决时停止，不得把风险转移到教师备注后继续生成。

课标导言中的一般理论表述，不得直接改写成“本课课标结论”。从一般理论到具体朝代性质的判断必须分别呈现课标原文、教材表述和证据或限定语。

## 标题定位

L1必须是有语义的环节名称，例如 `环节一·文明探源`，不得只写 `环节1`。L2对应本页知识板块，L3对应材料、子问题或知识点。

标题路径用于定位课堂进度，不替代材料、任务和知识内容。

## 文件一致性

- 中间构建文件使用 `draft.pptx`，不得与最终文件同名；
- 所有检查针对最终实际交付文件运行；
- 教师备注中的总页数、逐页标题、占位符数和动画页数必须与PPTX一致；
- 复制到任务根目录后重新计算文件哈希并再运行一次结构与课堂可用性检查。

## 能力边界

AI可以为教师后补的历史图片、地图、漫画和视频生成结构化占位符，但不能替教师完成素材身份、版权、图注和史实核验。课件交付时必须明确“媒体待教师替换”，而课堂链、知识点、问题、答案和结论仍须完整。

当复杂历史关系缺少已确认的节点、方向和限定语时，AI不得为了“设计感”自行绘制漂亮但失真的图示。应保留文字结构或请求教师确认。
