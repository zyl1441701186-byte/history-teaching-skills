# 教师备注模板

`教师备注.md` 必须与最终PPT页码和标题严格对应。

## 文件开头

```markdown
# 《完整课题名称》教师备注

- 课件文件：课堂课件.pptx
- 总页数：
- 总课时与时长：
- 核心问题：
- 教学主线：
- 动画控制方式：
- 外部媒体占位符数量：
- 文字溢出检查：通过/未通过
- 知识覆盖检查：通过/未通过

## 压缩授课路线
- 必讲页：
- 可压缩页：
- 可跳过页：
- 时间不足时的过渡说明：
```

## 逐页格式

```markdown
## 第8页｜一级标题 > 二级标题 > 三级标题

- 课堂属性：必讲／可压缩／可跳过
- 对应环节与知识ID：
- 本页目标：
- 初始画面：
- 操作顺序：
  1. 进入页面时……
  2. 第1次单击：……
- 教师提问：
- 预期回答：
  - 基础达成：
  - 完整达成：
  - 进阶表现：
- 追问与纠偏：
- 学生笔记落点：
- 核心结论：
- 页面过渡：
- 建议用时：
- 文字、数据与来源：
- 外部素材手动处理：
```

## 占位符填写

每个占位符记录：

```markdown
- 占位符ID：MEDIA-P12-01
- 教师选择：保留占位符／已有指定素材／暂不确定
- 建议素材：
- 教学作用与观察重点：
- 推荐比例、裁切和图注：
- 出现时机：
- 待核验：名称、年代、地点、机构、作者、版权、来源
- 教师插入方法：在同一区域替换，不改变文本和结论位置
- 不插入时的替代方案：
```

来源未核验前写“待教师补充”，不得推测填写。

## 学生视图禁区

教学意图、用时、完整预期回答、误区、制作提示、完整网址、必讲标记和内部检查信息只写备注，不显示在幻灯片。占位符说明属于交付后教师操作提示，可以暂时显示；教师插图后应删除说明文字。
