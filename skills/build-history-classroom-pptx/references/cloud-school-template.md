# 云校视觉语言文字规范

本规范是公开版在真实模板不可用时的兜底设计语言。仓库不附带学校模板文件；个人安装存在 `private-assets/templates/` 时，优先审阅真实模板，再以本规范校验关键色值和课堂硬规则。不得依据记忆仿制校徽、云校标识或其他官方图形。

## 风格选择

1. 用户在当前任务中明确提供并指定其他模板时，优先审阅该模板；
2. 本地私有覆盖层存在对应主题模板时，审阅该真实模板；
3. 对应真实模板不可用时，使用本文件的同主题文字规范；
4. 用户没有明确要求主题时，固定选择深色。

一套课件只使用一个版本，不在章节之间混用深浅体系，也不自行创建“中间色版本”。

## 固定画布与骨架

- 画布：16:9，33.867 cm × 19.05 cm；
- 所有常规内容页使用相同顶栏、底栏、页边品牌线和标题路径；
- 顶栏为L1教学环节，紧接其下为L2知识点，再下为L3子知识点（如有），内容区首行为当前任务；
- 内容区保留清晰外边界，结论条置于内容区内部；
- 右下可使用低对比度的原生几何水印，但不得冒充校徽、校园剪影或官方标识；
- 用户当前任务明确提供并授权校徽或品牌图形时才可使用，否则以纯文字课程名或通用品牌区替代。

## 课堂版式家族

统一页框内部至少使用四类构图，按内容选择：

- 单材料研读：媒体或材料占约45%—55%，问题、观察点和结论形成另一列；
- 图文任务：视觉证据居于视觉中心，图注、任务和结论围绕其组织；
- 比较归纳：真实表格或左右对照，比较维度明确，不用卡片墙；
- 时间与过程：时间轴、阶段带或流程关系，方向和节点层级清楚；
- 因果与制度：用连接线、箭头和层级表达关系，不用成排矩形代替逻辑；
- 知识总结：以板书式结构、关系网或结论带收束，保留学生笔记落点。

不得连续三页使用同一内部构图。除真实表格、时间轴或图示节点外，一页不得用五个以上同款矩形包装普通句子。

## 字体、字号与结论

- 标题：微软雅黑加粗，默认32 pt以上，最低28 pt；
- 普通正文：黑体加粗，默认28 pt以上，最低24 pt；
- 材料原文：楷体，默认26—28 pt，最低24 pt；
- 英文：Times New Roman；
- 结论条：白色微软雅黑加粗，32—36 pt，高度约1.6—2.0 cm，水平与垂直居中，最后出现并保持可见。

文字不适配时依次精简重复表达、改用合适版式、拆为同层级续页、把教师背景说明移入备注。不得自动缩字或突破字号下限。

## 手工重建与验收

1. 记录视觉来源模式；真实模板可用时先完整渲染和审阅，不可用时将本规范转写为任务内 `visual-language-spec.md` 和 `layout-system.json`；
2. 使用原生形状、文本、线条和表格从空白画布重建；
3. 所有学生可见内容保持可编辑，不使用模板截图或整页图片背景；
4. 顶栏、底栏、配色、字体、边界和品牌区全课一致；
5. 深浅版本不混用，新增课堂结构仍服从同一视觉语言；
6. 私有模板中的校徽、云校标识和校园剪影只用于授权的个人课件，不提取为公共资产；未获授权时不使用或仿制；
7. 最终PPTX无示例文字、默认提示语、空文本框、修复提示和制作残留。
