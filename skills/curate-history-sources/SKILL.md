# 目标

将用户已筛选的备课文件夹整理为 `资料核心摘要.md`。先完成本地遍历，再定向联网核验与补缺；以2025年修订文本组织当前课标要求，同时逐字列出2020年修订文本的对应原文并比较变化。

保留已有课件和教案的教学思路分析，推荐三条有课标、知识、材料与史学依据支持的教学主线。

本 Skill 只输出资料基础、主线建议和视觉证据需求。不得继续撰写教学设计、问题链、课堂活动、时间安排或课件。

# 必读规则

开始前完整读取：

- [references/source-policy.md](references/source-policy.md)
- [references/curriculum-comparison.md](references/curriculum-comparison.md)
- [references/visual-evidence-planning.md](references/visual-evidence-planning.md)

生成交付物前完整读取：

- [references/output-template.md](references/output-template.md)

课标基准文件为 [references/curriculum-standard-2017-2025.pdf](references/curriculum-standard-2017-2025.pdf)。不得根据文件名推测发文机关、文号或出版信息；版本身份和外部来源必须按课标对照规则核验并披露。

# 核心边界

允许：

- 递归遍历、提取、分类、去重和跨文件整合；
- 忠实概括本地资料中的普通知识内容；
- 定向联网查找课标、教材、史料、学术研究、数据、真题和教学思路；
- 生成可追溯的知识框架和两层材料库；
- 分析已有课件、教案和公开课的教学思路；
- 推荐一条最优和两条差异化备选教学主线；
- 提出图片、文物、地图、表格、示意图、漫画及音视频的具体需求。

禁止：

- 凭模型记忆补写史实、引文、数据、作者、版本、页码、网址或课标原文；
- 将搜索摘要、聚合页、转载页或AI内容作为正式证据；
- 将文学化标题伪装成史学概念或学术判断；
- 自创带定义性质的史学术语、概念或判断；
- 搜索、下载、筛选、嵌入或识别具体图片、地图、漫画和视频文件；
- 根据PPT转写文本猜测图片身份或图文关系；
- 将教学目标、问题链、探究任务和课堂流程混入资料摘要。

# 工作流

严格按以下顺序执行。未完成前一步，不得进入下一步。

## 1. 递归遍历本地资料

递归遍历用户指定或当前备课文件夹及其子文件夹。先建立读取清单，再提取内容。

排除隐藏缓存、临时文件、程序依赖、Skill文件和以前生成的摘要、教学设计、课件及其他AI输出。保留合法下载的原始资料，但不得把AI生成的来源记录当作原始证据。

音视频只在存在字幕或文字稿时纳入文本分析，否则仅登记文件名并说明未转写。图片、地图、漫画和PPT中的视觉对象不得仅凭转写文本推断身份。环境支持幻灯片渲染时，可对参考PPT执行低分辨率联系表审计，只用于识别版式、材料类型和视觉密度；具体对象仍须依靠图注、可靠正文或外部来源核验。只在教师选中页面后才提取原始媒体，禁止预先批量展开全部图片。

报告发现、成功读取、无法读取和主动排除的文件数量，列出未成功读取文件。存在未读文件时不得声称100%完成。

## 2. 建立双版本课标依据

使用2025年修订文本作为当前教学要求基准，同时检索并打开教育行政部门发布的2020年修订文本。

针对本课必须：

1. 定位2025年对应专题的完整原文、PDF页码和版面页码；
2. 定位2020年对应专题的完整原文、PDF页码和版面页码；
3. 并列呈现两版原文，不得只给概括；
4. 标明增写、删减、替换、顺序调整或表述不变；
5. 解释变化对知识范围、能力要求、素养指向和教学重点的影响；
6. 无法建立准确对应时明确说明，不得强行逐句匹配。

课程标准、教材和教学资料的表述必须分开。资料中的教学目标不得冒充课标原文。

## 3. 整合本地内容

将本地资料视为用户已筛选的工作语料：

- 普通知识可用于知识框架、教学思路和主线判断；
- 每项提取结果记录来源文件及页码、幻灯片编号、表格或其他可定位位置；
- 史料原文、数据、署名观点和视觉材料身份执行严格出处核验；
- 缺失字段标记待核，禁止推测补全；
- 不同资料冲突时并列记录并按来源政策处理。

先跨文件聚类、去重和整合，再保留代表来源和差异，不按单个文件生成冗长摘要。

## 4. 建立知识、证据和素材需求缺口

依据双版本课标、教材和本地资料建立具体知识框架。知识点精确到史实、制度、过程、概念或历史关系，不得只写宽泛主题。

逐项检查：

- 2025年课标新增或调整要求是否落实；
- 每个知识点是否有可靠文字、数据或教材证据；
- 重点难点是否具有互证、比较或递进材料；
- 是否需要图片、文物、地图、表格、示意图、漫画或音视频辅助；
- 本地教学思路是否同质化；
- 是否存在日期、译名、数据、版本或观点冲突。

将缺口转化为具体联网目标。禁止宽泛搜索课题名称并批量摘录。

## 5. 自动定向联网

联网只用于：

1. 查找并核验双版本课标；
2. 补全本地文字材料出处；
3. 核验冲突；
4. 补充核心知识证据、学术解释、数据和真题；
5. 查找优秀课件、教案、公开课和教学论文的教学思路；
6. 为视觉素材建议提供权威检索方向和核验字段。

不在本环节搜索或下载具体图片、地图、漫画和视频文件；不得引用搜索缩略图。视觉需求只写“需要什么、为什么需要、如何核验、教师可如何搜索”。

每个具体目标最多三轮有效检索：先找权威或原始来源，再更换关键词或来源类型，最后追查缺失字段。找到合格资料、结果重复、内容偏离或三轮后仍无可靠来源时停止。

必须打开完整网页、PDF或原始页面再判断。联网不可用时继续完成本地部分并披露，禁止模拟联网。

## 6. 建立知识框架和两层文字材料库

建立：

- `核心可用材料库`：已核验且适合进入教学设计的文字、数据、教材栏目和题目；
- `备选材料索引`：重复、出处不完整、课堂适配较弱或仅作线索的内容。

知识点数量由课标和教材决定，不以6至12个为目标。每个核心知识点必须有可靠依据，或明确报告缺口。重点难点优先保留功能不同的互证、比较或递进材料。

## 7. 建立多模态视觉证据建议库

只规划素材意图，不选择真实文件。先按知识板块建立“知识点—证据任务—最合适媒介”的覆盖矩阵，再为每项建议分配 `VS-01` 起的编号，并写明：

- 对应知识点和可能使用环节；
- 素材类型；
- 希望呈现的具体对象、范围和信息；
- 教学功能和学生观察重点；
- 必要程度：A级核心证据、B级辅助理解、C级装饰；
- 建议画幅、地图范围或视频时长；
- 教师搜索关键词和优先来源类型；
- 必须核验的名称、年代、地域、图例、作者、馆藏、版权或视频时间点；
- 无素材时的非口述替代方案。

C级素材原则上不建议进入课件。不得写“使用一张相关图片”等空泛建议。

视觉证据不得被视为可有可无的装饰。每个主体知识板块至少判断一次文物、地图、遗址、图像、表格、示意图、漫画或音视频是否能够承担证据、时空定位、比较或机制解释功能。

40至45分钟的一课时默认规划8至12项A/B级视觉建议，至少覆盖3种媒介类型。少于6项，或出现连续多个主体板块均为纯文字时，必须逐项说明证据与教学理由，并标记 `视觉证据覆盖不足，待教师确认`。不得为凑数加入无关材料。

每个主体教学板块至少有1项A/B级视觉候选；核心重难点优先形成2项功能互补的视觉或图文证据。导入使用的文物不得成为全课唯一反复使用的图片。

## 8. 归纳已有教学思路

跨文件聚类本地课件、教案和网络教学资料。说明每类思路的核心立意、知识组织、代表材料、代表来源、优势和局限。相似思路合并，独特思路单列。

教学资料只能支持教学思路判断，不能替代历史事实来源。无法读取PPT视觉内容时，只能分析可读取文字，不得声称理解了完整视觉设计。

## 9. 推荐三条教学主线

生成一条最优推荐和两条实质差异的备选。每条包含：文学化标题（可选）、规范主线表述、主线类型、核心立意、核心问题、知识组织逻辑、覆盖知识点、核心材料、课标对应、史学理论或概念依据、适用取向、优势和风险。

主线类型只能是：

- `资料原有主线`
- `跨资料整合主线`
- `AI综合建议`

文学化标题可以浪漫化，但必须与学术表述分栏。凡涉及史学判断、专业概念或定义，必须给出课标、教材、通行史学概念或具体学者著作依据。找不到依据时改用中性、描述性表述，禁止制造“有意义之变”等自创概念。

按照课标匹配度、知识覆盖度、材料支撑度、史学依据、探究价值和一课时可行性评价。三条主线至少在两个关键维度上实质不同，不得只换标题。

主线止于立意、核心问题和知识组织，不得生成完整教学过程。

## 10. 输出与停止

严格按输出模板生成 `资料核心摘要.md`。完成质量检查后停止，不得自动进入教学设计或课件制作。

# 关键失败处理

- 2025课标文件无法读取：停止，不得改用模型记忆。
- 2020课标原文无法从可靠来源取得：保留2025原文并报告对照未完成，不得伪造差异。
- 无法读取本地文件：列入审计，不得假装已读。
- 出处不完整：移入待核或备选区。
- 可靠来源冲突：并列呈现，不得无依据裁决。
- 视觉内容缺少可验证信息：只保留为素材需求或候选线索。
- 视觉建议少于一课时最低审计线：保留现有建议并报告不足，不得用空泛“相关图片”补数。
- 网络搜索失败：保留本地结果和未解决目标，不得编造。
