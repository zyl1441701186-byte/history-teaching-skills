# 目标

在教师指定的资料文件夹内创建本次备课目录，完成本地资料整合、必要的网络补证和教学主线建议，只交付 `资料摘要.md`。

# 核心规则

- 本地资料是主要工作语料；网络只用于课标核对、出处补全、冲突核验和核心缺口补证。
- 历史事实、史料原文、数据、学者观点和课标表述必须来自已读取的本地文件或已打开的完整网页、PDF，不得凭模型记忆补写。
- 搜索摘要、聚合页、转载页和AI生成内容只能帮助发现来源，不能直接作为证据。
- 普通知识可以忠实概括；逐字引文、数据和署名观点必须给出作者或机构、文献或页面名称、页码或网址等可定位信息。
- 无法核验的内容进入“待核与缺口”，不得送入后续教学设计。
- 无法直接读取参考PPT时，只分析可读取文字；不得根据转写文本猜测图片身份和图文关系。
- 不搜索、下载或筛选具体图片和视频文件，只说明建议使用什么素材、承担什么教学功能、教师应核验什么。
- 教学主线中的专业概念和史学判断必须有课标、教材、通行概念或学者著作支持；文学化标题不得冒充学术概念。

# 工作流

## 1. 建立任务目录

取得课标题，在教师指定资料文件夹内创建：

```text
yyyyMMdd-HHmmss_Trae_课标题/
```

本轮及后续两个Skill的新文件都保存在该目录。原始资料只读；遍历时排除本任务目录，避免把AI输出重新当作来源。

## 2. 遍历本地资料

递归读取资料文件夹，先列出发现、成功读取和未成功读取的文件。音视频有字幕或文字稿时分析文字，否则只登记名称。图片和PPT视觉内容只有在环境能够可靠渲染且存在图注时才分析。

跨文件归纳以下内容：

- 课标与教材要求；
- 基础史实、概念、过程、原因、特点和影响；
- 可直接用于课堂的史料、数据、表格和试题；
- 已有课件或教案的教学思路；
- 来源冲突、材料不足和视觉证据需求。

相似内容合并，不按文件逐篇写摘要。

## 3. 对照双版本课标

优先使用教师本次提供的2025年修订版PDF；未单独提供时检查本Skill的 `assets/curriculum-standard-2017-2025.pdf`。同时从教育行政部门或权威出版渠道取得2020年修订文本。

针对本课：

1. 并列列出2025年和2020年对应原文及页码；
2. 标明增写、删减、替换、顺序调整或表述不变；
3. 简要说明变化对知识范围、能力要求和教学重点的影响。

无法确认对应关系时直接说明，不强行逐句匹配。

## 4. 定向联网补证

先写出具体缺口，再搜索。优先顺序为：

1. 政府、教育行政部门、博物馆、档案馆等原始或官方来源；
2. 正式出版物、学术机构和学术论文；
3. 权威媒体和专业教育平台；
4. 其他网页只作线索。

打开完整页面或PDF后再采用。一个缺口经过合理的关键词和来源调整仍无法解决时停止搜索并报告，不进行无边界漫游。

## 5. 整理教学可用资料

按照“知识点—可用证据—课堂用途”整理，不追求材料数量。优先保留能支持比较、解释、判断和形成结论的材料。

为图片、文物、地图、表格、示意图、漫画和音视频提出具体建议，写明：

- 建议对象；
- 对应知识点；
- 学生观察或处理任务；
- 教学作用；
- 教师需要核验的信息；
- 没有该素材时的替代方案。

## 6. 推荐教学主线

默认推荐一条最合适主线；只有另一方案确有不同价值时再提供一个备选。

每条主线说明：

- 文学化标题（可选）；
- 规范的历史学表述；
- 核心问题；
- 知识组织方式；
- 主要材料；
- 理论或概念依据；
- 优势、风险和一课时可行性。

区分导入锚点与教学主线。一个文物只在开头和结尾出现时，只能作为导入锚点，不能宣称贯穿全课。

# 输出

在任务目录中生成 `资料摘要.md`，包含：

1. 课题与资料读取情况；
2. 双版本课标原文及变化；
3. 核心知识框架；
4. 可直接使用的文字、数据和试题材料；
5. 多类型素材建议；
6. 已有教学思路归纳；
7. 推荐主线及依据；
8. 待核内容、材料缺口和来源清单。

只交付这一份文件。完成后停止，不自动进入教学设计。
