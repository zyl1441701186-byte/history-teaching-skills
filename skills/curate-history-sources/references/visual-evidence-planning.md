# 多模态视觉证据规划

## 目的

视觉材料首先是历史证据和认知支架，不是装饰。为每个主体知识板块判断最合适的媒介，再决定是否形成素材建议。

## 媒介功能

| 类型 | 首要功能 | 必须说明 |
|---|---|---|
| 文物、遗址、档案图像 | 实物证据、细节观察 | 观察什么、能支持什么、不能推出什么 |
| 历史地图 | 时空定位、范围与关系 | 年代、范围、图例、边界和观察任务 |
| 多图比较 | 比较生产、文化或制度差异 | 比较维度和学生输出 |
| 表格、数据 | 变化、差异和结构 | 口径、单位、比较维度 |
| 时间轴 | 过程与阶段 | 时间尺度和阶段划分依据 |
| 制度、因果示意图 | 机制和关系 | 节点、关系、方向和结论 |
| 漫画 | 立场、矛盾和观念 | 作者、语境和立场 |
| 音视频 | 动态过程或必要情境 | 片段时长、时间点和观看任务 |

## 覆盖审计

建立：

| 知识板块 | 核心问题 | 现有文字证据 | 建议视觉证据 | 功能 | A/B级 | 无素材替代 | 覆盖状态 |
|---|---|---|---|---|---|---|---|

40至45分钟课时以8至12项A/B级视觉建议为默认目标，至少3种类型。数量不是独立质量标准；但少于6项时必须报告原因并请求教师确认。

避免：

- 只有导入使用一张文物，后续全部纯文字；
- 同一图片在导入、过程和总结中机械重复；
- 用装饰图替代史料或地图；
- 只写“相关图片”“适当视频”；
- 把无法核验的画面当作史实证据。

## 参考PPT轻量审计

环境能够渲染PPT时：

1. 生成低分辨率联系表，每张缩略图约320×180像素，每张联系表6至9页；
2. 只记录页码、构图、可见材料类型、视觉密度和可能的教学用途；
3. 不凭缩略图确认文物、地图或人物身份；
4. 教师选择具体页面后，才提取对应原始媒体或读取高分辨率页面；
5. 联系表和提取文件只留在任务工作区，不进入交付物。

若无法渲染，只分析可读取文字并披露视觉未审计。
