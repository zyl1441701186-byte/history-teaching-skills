# 来源分级、概念核验与视觉边界

## 1. 本地资料

用户文件夹是已经筛选的工作语料。普通知识可用于知识框架、教学思路和主线判断，但必须记录文件名和精确位置。

史料原文、数据、署名学术观点、图片地图身份和课标原文实行严格核验。作者、译者、版本、页码、年代、原始载体或图注缺失时禁止猜测。

本地资料冲突时依次参考：课程标准和教材原文、教师教学用书及教材出版社资料、正式学术出版物、优质教学设计、普通课件。无法解决时并列保留。

## 2. 网络来源等级

一级来源：教育行政部门正式文件；教材出版社；档案馆、博物馆、图书馆；大学和研究机构原始文献数据库；政府和国际组织原始材料；正式学术出版物。

二级来源：专业学会、研究机构、大学课程资料、有作者和参考文献的研究文章、能够回指原始文献的高质量二手研究。

三级来源：教研平台、名师工作室、学校公开课、教学比赛课件、教师博客和商业教育平台。只用于教学思路，不用于单独确认史实、引文、版本或学术观点。

四级来源：百科、聚合页、论坛、社交媒体、文库转载、搜索摘要、AI生成页面。只作搜索线索。

## 3. 最终状态

- `可直接使用`：满足对应材料的核验标准。
- `转引或有条件使用`：来源可靠但未直接查阅原始载体，保留限定说明。
- `仅作线索`：不得进入后续教学设计的证据白名单。

## 4. 核验标准

史料原文：打开完整页面、PDF或扫描页，确认作者、载体、版本和精确位置。不同位置文字不得拼成连续原文。OCR不确定字符使用 `□`。

一般史实：一项一级来源明确支持，或两项相互独立的二级来源一致支持。

学术观点：确认作者、著作或论文、出版信息和观点语境，保留归属表达。

数据：确认时间、地域、指标、单位、口径、原始数据和来源位置。

真题：确认年份、地区或卷别、考试名称和题号。无法确认时只能写“现成练习题”。

## 5. 主线概念合法性

主线中的学术概念按以下顺序核验：

1. 课程标准或教材正式概念；
2. 史学界通行概念；
3. 有明确学者、著作和语境支持的学术表达；
4. AI临时创造的词语。

第四类不得承担主线的学术解释功能。文学化标题可以自拟，但必须与规范主线表述分开，不能通过冒号、引号或自行下定义把文学修辞包装成专业术语。

## 6. 视觉与音视频边界

本 Skill 不搜索、下载、选择、嵌入或确认具体图片、地图、漫画和视频身份。只生成需求建议。

建议必须写明具体对象、教学作用、观察任务、必要程度、比例或时长、搜索关键词和核验字段。无法说明教学功能的装饰素材不推荐。

本地文件名、图注或附近正文可以作为线索，但不得据此断定实际画面。PPT转写文本不能证明图片与正文一一对应。

环境支持时允许把参考PPT渲染成低分辨率联系表，用于判断材料类型、视觉密度和教学构图；不得据此确认具体史实身份。只有教师选择某页后，才读取高分辨率页面或提取对应媒体进行后续人工核验。

## 7. 网络来源记录

每项采用的网络文字或数据材料至少记录：材料ID、标题、作者或机构、日期或版本、原始URL、访问日期、精确定位、来源等级、核验状态及其支持的知识点。

缺失字段必须显式标记，禁止根据常识补全。
