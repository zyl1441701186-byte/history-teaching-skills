# 多类型材料意图与教师确认接口

## 总原则

教学设计阶段不搜索、不下载、不选择、不识别真实图片、地图、漫画和视频。只说明需要什么素材以及如何用于教学。

外部视觉素材由教师在PPT制作前逐页决定是否使用。后续PPT Skill 依据教师选择生成纯文字版式或带明确说明的占位符。

教师可以选择保留占位符并在交付后手动替换。占位符只影响媒体状态，不得使知识、课堂任务、答案或结论处于待补状态。

## 素材建议字段

每项建议包含：

- 建议ID和上游 `VS` ID；
- 对应教学环节、子问题和知识点；
- 素材类型；
- 具体内容要求；
- 教学功能；
- 学生观察或处理任务；
- 必要程度A/B/C；
- 推荐画幅、地图范围或视频时长；
- 首次出现和答案揭示顺序；
- 必须核验的身份、年代、地点、图例、作者、馆藏、版权或时间点；
- 教师搜索提示；
- 不使用时的替代教学方案。

## 三级素材

- A级：核心证据。缺少会使活动无法成立；可以保留占位符交付，但必须标记为“授课前必补”，并同时给出明确的观察任务和核验要求。
- B级：辅助理解。可以由文字、表格、时间轴或原生示意图替代。
- C级：装饰。原则上不进入课件，也不设置占位符。

## 可直接生成的原生视觉

当内容完全来自已核验知识或数据时，允许后续PPT原生生成：

- 表格；
- 时间轴；
- 因果关系图；
- 制度运行示意图；
- 概念层级图；
- 简单统计图。

不得用原生图形伪造历史地图、文物、档案或原始图像。

## 教师确认选项

PPT制作前每页只允许选择：

- `不使用素材`：删除占位需求，重新安排纯文字或原生图形版式；
- `保留占位符`：按建议内容、比例和位置生成占位框；
- `已有指定素材`：记录文件名或描述，但仍只生成对应占位符，由教师交付后手动插入；
- `暂不确定`：保留可删除占位符，并提供无素材替代方案。

设计 Skill 不代替教师做最终选择。

占位页仍需规划文字证据或知识支架、学生任务和结论位置，不得让空框成为整页唯一教学内容。

## 覆盖要求

- 每个主体教学环节至少提出1项A/B级视觉候选；
- 核心重难点优先配置2项功能互补材料；
- 40至45分钟课时默认8至12项A/B级建议，至少3种类型；
- 少于6项时明确标记覆盖不足并请求教师确认；
- 导入文物不得机械重复为总结页唯一视觉；
- 不因尚无真实文件而删除占位需求。
