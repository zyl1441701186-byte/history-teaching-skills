# History Teaching Skills | 高中历史AI备课工作流

一套面向高中历史教师的 AI 备课工作流技能集，涵盖**资料筛选**、**教学设计**、**课件制作**三大环节。三个 Skill 逐级衔接，从原始备课文件夹到可交付的课堂 PPTX，形成完整的数字化备课链路。

## 为什么做这个

高中历史备课长期面临三个痛点：资料分散且来源混杂、教学设计靠经验难以系统化、课件制作耗时且质量不稳定。本套技能将一线教师的实践经验编码为可复用、可迭代的 AI 工作流规则，让 AI 成为可靠的备课助手而非黑箱。

核心设计原则：

- **证据可追溯**：每条史料、数据、观点都必须有来源和核验状态，禁止 AI 凭记忆补写
- **知识不偷工**：课件必须落实知识覆盖矩阵，主线修辞不能替代基础知识
- **视觉证据不过度保守**：每个主体环节主动规划文物、地图、遗址、图表等证据，由教师逐页确认后手动替换
- **反商务化**：课件面向真实课堂，禁止仪表盘、卡片墙、KPI 模板

## 三个 Skill 及协作关系

```
备课文件夹 ──► [curate-history-sources] ──► 资料核心摘要.md
                  资料筛选与课标对照              │
                                                 ▼
               [design-history-lesson] ──► 教学设计.md
                  教学设计与问题链              课件制作清单.md
                                             课件素材建议表.md
                                                 │
                                                 ▼
              [build-history-classroom-pptx] ──► 课堂课件.pptx
                  课件制作与验收                   教师备注.md
```

### 1. curate-history-sources — 资料筛选与课标对照

遍历教师已筛选的备课文件夹，核对 2017 年版 2025 年修订与 2020 年修订双版本课程标准，定向联网补证，生成可追溯的资料核心摘要、知识框架、两层材料库和多模态视觉证据建议，并推荐三条有学理依据的教学主线。

- 本地遍历 → 课标双版本对照 → 知识缺口分析 → 定向联网补证 → 材料分级核验 → 三条教学主线
- 严格区分来源等级（一至四级），史料原文必须打开完整页面核验
- 不撰写教学设计，不制作课件，不搜索/下载图片视频
- 40—45 分钟课时默认规划 8—12 项 A/B 级视觉证据；参考 PPT 采用低分辨率联系表轻量审计

### 2. design-history-lesson — 教学设计与问题链

基于已确认的资料核心摘要和教学主线，生成以教学环节组织、知识覆盖完整、史学概念严谨的完整教学设计，并输出课件制作清单和素材建议表。

- 知识覆盖矩阵 → 学习结果与评价 → 核心问题与问题链 → 导入设计 → 教学过程 → 板书与作业
- 导入必须通过可见对象（文物/时事/史学家表达）让学生提出核心问题，禁止纯口述
- 教学主线表述必须有明确史学理论支撑，禁止自创术语
- 每个拟定页面输出独立 L1/L2/L3 标题路径、构图家族、视觉中心、互动表格和图示结构接口
- 多类型材料组合（地图、图片、表格、示意图、漫画等）服务于不同认识功能

### 3. build-history-classroom-pptx — 课件制作与验收

根据已确认的教学设计、课件制作清单和素材建议表，生成原生可编辑、知识覆盖完整、带规范占位符和逐页教师备注的 PowerPoint 课件。

- 逐页蓝图 → 视觉证据覆盖审计 → 教师素材确认 → 原生 PPTX → 原生动画 → 结构与视觉双重验收
- 默认采用文字固化的深色云校视觉语言，支持浅色版本；仓库不附带、不依赖原模板文件
- 所有常规页面使用独立 L1/L2/L3 标题对象，双版本课标原文必须进入课件
- 互动表格使用真正空单元格，答案文本框在同一页逐项出现；禁止括号占位和重复答案页
- 新增成品结构检查，拦截错误总页码、制作残留、矩形过载和标题缺失

## 适用场景

- 高中历史教师日常备课（统编教材）
- 需要系统化管理备课资料和教学设计的教研组
- 对 AI 辅助备课有兴趣但需要可控、可追溯流程的教育工作者
- 历史教育方向的师范生和新教师培训

## 前置依赖

- [TRAE](https://www.trae.ai/) 或兼容的 AI 编程环境（支持 Skill 机制）
- 课件制作 Skill 需要 Windows + PowerPoint（用于原生动画和溢出检查）
- [PptxGenJS](https://github.com/PptxGenJS/PptxGenJS)（课件生成引擎）
- 课程标准 PDF 文件（2017 年版 2025 年修订文本）

## 安装

将 `skills/` 目录下的三个子文件夹复制到你的 TRAE Skills 目录中：

```
<TRAE_SKILLS_DIR>/
├── curate-history-sources/
│   ├── SKILL.md
│   └── references/
├── design-history-lesson/
│   ├── SKILL.md
│   └── references/
└── build-history-classroom-pptx/
    ├── SKILL.md
    ├── agents/
    ├── references/
    └── scripts/
```

> **注意**：`curate-history-sources` 附带的 `curriculum-standard-2017-2025.pdf` 因体积原因未包含在仓库中，请自行获取并放置于 `references/` 目录下。

## 使用方式

### 完整流程（推荐）

1. 将备课资料放入一个文件夹
2. 调用 `curate-history-sources`，指定备课文件夹路径，生成 `资料核心摘要.md`
3. 确认教学主线后，调用 `design-history-lesson`，生成教学设计和课件制作清单
4. 完成逐页素材确认后，调用 `build-history-classroom-pptx`，生成课件和教师备注

### 单独使用

每个 Skill 也可以独立使用，只要满足各自的启动条件（详见各 SKILL.md）。
